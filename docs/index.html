A real app, not snippets

A small support desk with an inbox, a reply box and a weekly report. Run it with npm start and click the buttons.

No API key to start

Replay mode uses pre-written answers for the sample emails. Add a key to run every button live against Claude.

Built to be trusted

Schemas, checks in plain code, "unknown" as an answer, a person in charge, fallbacks, and a small eval suite.

The lessons

1 Tidy up Suggest edits, let people pick, apply with plain code. 2 Fill from email Messy email in, form fields out. Unknown stays unknown. 3 Route it A cheap model sorts, code routes, a specialist answers. 4 This week's themes Fan out over 24 tickets, combine, let code count. 5 Draft and check Writer, rule checker, one targeted fix, then a person. 6 Ship it Prompt injection, failures, cost per click, evals. + Design your own AI button Five questions for designing your own AI button.

Run it in a minute

git clone https://github.com/georgehanu/ai-buttons.git
cd ai-buttons
npm install
npm start

Node.js 20 or newer. Then open http://localhost:3000.
